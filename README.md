
# Advanced E-Commerce Customer & Business Analytics

## Project Overview
This project focuses on analyzing Indian e-commerce sales, customer behavior, product performance, and business operations using Python, MySQL, Excel, and Power BI.

The project uses a synthetic e-commerce dataset designed to simulate real-world business scenarios and demonstrate end-to-end data analytics skills.

## Project Objectives
- Analyze sales and revenue performance.
- Understand customer purchasing behavior.
- Identify valuable customer segments using RFM analysis.
- Evaluate product and category performance.
- Analyze delivery operations, returns, and payment methods.
- Generate actionable business insights.

## Dataset Information
The project uses the **Indian E-Commerce Sales & Customer Analytics** dataset.

The dataset contains 9 main tables:

1. Customers
2. Products
3. Orders
4. Order Items
5. Payments
6. Shipments
7. Returns
8. Customer Reviews
9. Marketing Campaigns

**Note:** The dataset is synthetic and is used for analytical and portfolio purposes.

## Key Business Insights
- 82.87% of purchasing customers are repeat buyers.
- 41.76% of shipments were delayed.
- Fashion recorded the highest number of returns (3,185).
- Electronics recorded the highest refund value (approximately ₹52.11 million).
- Organic Search generated approximately ₹76.66 million in revenue.
- Direct/App recorded the highest marketing ROI of 5.20.
